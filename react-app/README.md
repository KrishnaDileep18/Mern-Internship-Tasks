# Job Portal Application

A simple Job Portal web application built using React.

## 🚀 Features

- User Login Page
- Jobs Listing Page
- Fetches jobs from Remote Jobs API
- SearchBar component to filter jobs
- Responsive UI design

---

## 🔍 SearchBar Feature

I added a reusable SearchBar component.

### What it does:
- Allows users to search jobs by keyword
- Filters job listings in real time
- Updates results dynamically

### How it works:
- Uses React useState to store search text
- Sends input value to parent component using props
- Filters jobs based on title or company name

## 🛠️ Technologies Used

- React
- React Router
- CSS
- Fetch API
